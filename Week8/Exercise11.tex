\section{Step 1: Organize the Dictionary}

We will store each phone number as a dictionary key.  The value
will be a list containing the person's first and last name.

\begin{verbatim}
phone_book = {
    "562-555-0142": ["Maria", "Garcia"],
    "562-555-0188": ["Daniel", "Kim"],
    "562-555-0125": ["Elena", "Garcia"],
    "562-555-0171": ["Maria", "Lopez"],
    "562-555-0194": ["Aisha", "Patel"]
}
\end{verbatim}
\noindent
For one entry,
\begin{verbatim}
phone = "562-555-0142"
person = phone_book[phone]
\end{verbatim}
\noindent
Check the following for one entry: \texttt{person[0]} and \\ \texttt{person[1]}.

\section{Step 2: Add a Contact}

Write a function that adds a new entry:

\begin{verbatim}
def add_contact(ph_book,phone,first,last):
    ph_book[phone] = [first, last]
\end{verbatim}
\noindent
Test it with
\begin{verbatim}
add_contact(
    ph_book,
    "562-555-0110",
    Marcus","Johnson"
)
\end{verbatim}
\noindent
Print the contents of \texttt{ph\_book} to check it.
